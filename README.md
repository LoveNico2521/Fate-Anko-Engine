# 織夢者菲特《Fate》 - 安科劇情推演系統

菲特：「把命運交給我吧，主人喵。」(๑•̀ㅂ•́)و

一顆為安科／安價而生的骰子。整個系統就是**一個 HTML 檔**——不用安裝、不用連網，
瀏覽器打開，菲特就開始織。深色介面，手機也能滾。

## 她會做什麼

- **連鎖判定** — 骰出觸發值就一路滾下去，逐層展開（想停？骰子不同意）
- **ra / ro 雙模式** — 低於目標成功，或高於門檻成功，安科規則說了算
- **d4 到 d100** — 骰數、加值（Boost）自由配，1d100 還有三種 Boost 演算法可以切
- **多組連鎖** — 一次一組不夠看？那就一次丟好幾組，自動標記第 N 組
- **織夢紀錄** — localStorage 幫你記著，重新整理也忘不掉；想賴帳才清空
- **匯出 CSV** — 紀錄要拿去發文？打成包直接帶走

### 除錯用（一般玩家不用理）

頁面上有個**偵錯序列**輸入欄（`debug-seq`）：手動指定骰值序列，重現特定推演結果。
這是開發時驗證邏輯用的工具，不是玩法喵。

## 檔案

| 檔案 | 是什麼 |
|---|---|
| `fate-anko-engine.html` | 全部。點開就能玩 |
| `main.py` | 想要桌面視窗的話（pywebview） |
| `CHANGELOG.md` | 43 個版本怎麼長成現在這樣，逐版寫清楚 |
| `legacy/` | 開發考古層：43 個 HTML 迭代、9 個 Python、229 個片段。好奇再開 |

## 用法

網頁版：雙擊 `fate-anko-engine.html`。沒了。

桌面版：

```bash
pip install pywebview
python main.py
```

要打包成 exe 再說：`pyinstaller --onefile main.py`
